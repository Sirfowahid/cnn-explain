CNNs, step by step

Convolution, the CNN pipeline and the classic architectures. Set the image and kernel at the top, use the controls inside each step for stride, padding and pooling, press Play, and click any number to see how it was calculated.

The images are tiny hand-made examples; real kernels are learned from data, not chosen by hand. Parameter counts and multiply-adds are computed from the layer lists shown (BatchNorm weights included where a network uses it), so published totals may differ slightly.
